# hexo-theme

Postdare 的 Hexo 主题 —— 编辑体（editorial）风格：发丝线分隔、琥珀金强调色、等宽字体承载元信息，支持明暗双主题。

- 仓库：https://github.com/postdare/hexo-theme
- 站点：https://blog.postdare.com

## 构建

样式基于 Tailwind CSS，`source/css/tailwind.css` 为源文件，编译产物 `source/css/main.css` 已纳入版本控制。

```bash
npm run build:css   # 单次构建
npm run watch:css   # 监听模式
```
